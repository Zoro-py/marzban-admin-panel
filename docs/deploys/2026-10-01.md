# Deploy 2026-10-01 — gzip فرانت (رفع «پنل روی موبایل باز نمی‌شود»)

**محدوده:** فقط `frontend/nginx.conf` — بدون backend، بدون migration، بدون env جدید، بدون دست‌زدن به Marzban.

## چه شد
- لاگ زندهٔ فرانت: کلاینت Android/Irancell (5.239.173.104) ساعت 01:20–01:24 UTC صفحه و CSS را گرفت ولی باندل اصلی ~۴۸۴KB هرگز کامل نرسید → صفحهٔ سفید. کلاینت لپ‌تاپ از مسیر VPN می‌گذرد و مشکل ندارد — برای همین «لپ‌تاپ باز می‌شود، موبایل نه».
- هیچ فشرده‌سازی در زنجیره فعال نبود (CSS خام 85,870 بایت).

## کامیت‌ها
- `e22fafd` — gzip level 6 + gzip_types + vary/min_length.
- `792cab6` — `gzip_http_version 1.0`؛ هاست nginx با proxy_http_version پیش‌فرض 1.0 به کانتینر پروکسی می‌کند و nginx بدون این خط درخواست 1.0 را فشرده نمی‌کند (اولین دیپلوی Vary داد ولی Content-Encoding نه).

## دیپلوی و smoke
- `git pull && docker compose up -d --build frontend` روی france-vpn (فقط سرویس frontend).
- باندل جدید `index-CR0V7Cv6.js`: 484,411 → **148,307 بایت** با `Content-Encoding: gzip` (≈69٪ کاهش)؛ CSS هم فشرده؛ `GET /` 200؛ `ops-api/api/health` 200؛ صفحهٔ لاگین در مرورگر سالم رندر شد.
- هش‌های asset بعد از rebuild عوض شده‌اند (طبیعی Vite) — tab باز قبلی با refresh جدید می‌گیرد؛ کانفگ no-cache روی index.html از قبل همین را پوشش می‌داد.
