## ریسک‌ها

1. رفع‌های پولی مسیر تسویهٔ ماهانه را عوض می‌کنند — دقیقاً همان مسیری که بدونشان شکست
   قطعی داشت؛ رفتار HTTP بقیهٔ endpointهای settle دست‌نخورده است (فقط گارد فراخوانی مستقیم).
2. `mark_batch_paid` از threadpool به event loop می‌رود (async) — بدنهٔ دیتابیسیِ کوتاه،
   هم‌الگوی settleهای موجود.
3. بات: `/bulk` بدون فلگ جدید همان preview را می‌دهد ولی صفحهٔ confirm سه دکمه دارد —
   رفتار قدیمیِ «بدون مالک» هنوز صریح موجود است.
4. فرانت: تغییرات افزایشی (فیلد جدید اختیاری‌رفتار، برچسب) — rollback = checkout کامیت قبلی.

## rollback

```bash
ssh france-vpn   # در /opt/marzban-admin-panel
git log --oneline -3            # پیدا کردن main قبلی
git checkout <main-قبلی> && docker compose up -d --build
```
(هیچ migration/data-changeای برای برگرداندن نیست؛ DB دست‌نخورده می‌ماند.)
