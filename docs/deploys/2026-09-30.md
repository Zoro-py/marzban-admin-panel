## دیپلوی (فقط بعد از GO مالک — این دور طبق پرامپت دیپلوی نمی‌کند)

```bash
ssh france-vpn   # در /opt/marzban-admin-panel
git fetch origin && git log --oneline main..origin/main   # بازبینی
git pull --ff-only origin main
docker compose up -d --build frontend    # فقط frontend — backend/bات‌ها/Marzban دست‌نخورده
```

**راستی‌آزمایی بعد از دیپلوی:** ‏`GET /` → 200؛ رشتهٔ «نسخهٔ پنل به‌روز شده است» داخل باندل
تازه حاضر است (`docker exec marzban-admin-panel-frontend-1 grep -rl "به‌روز شده" /usr/share/nginx/html/assets | head -1`)؛
دستی موبایل: پنل را باز کنید، یک دیپلوی تست، بدون بستن تب به یک صفحهٔ دیگر بروید — باید یا
خودش reload شود یا بنر فارسی بدهد (نه سفیدصفحه).
